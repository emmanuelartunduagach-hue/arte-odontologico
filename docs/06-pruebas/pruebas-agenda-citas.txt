PASO 1 - Base de datos (Workbench: File > Open SQL Script y ejecutar con el rayo)
--------------------------------------------------------------------------------
Opcion A (recomendada, en desarrollo no hay datos reales): base desde cero
    backend\database\schema.sql
    (si ya existe la base, antes:  DROP DATABASE arte_odontologico;)

Opcion B: conservar la base actual, ejecutando EN ORDEN y una sola vez:
    backend\database\migraciones\001_alta_pacientes_por_administrador.sql
    backend\database\migraciones\002_especialistas_y_citas_sin_usuario.sql
    (la 002 borra franjas y citas de prueba; usuarios y servicios se conservan)

Con la opcion A hay que volver a crear el administrador:  npm.cmd run crear-admin


PASO 2 - Agregar al backend\.env
--------------------------------
    URL_PUBLICA=http://localhost:5500
    WHATSAPP_MODO=consola
    HORAS_MINIMAS_GESTION=24
    LIMITE_CITAS_ACTIVAS_SIN_USUARIO=1

"consola" imprime cada WhatsApp en la terminal del backend (para probar y
para la demo). "manual" lo deja pendiente para enviarlo desde el panel.
Luego:  npm.cmd run dev


PASO 3 - En PowerShell, pegar estas funciones (una vez por terminal)
--------------------------------------------------------------------
    $API = 'http://localhost:3000/api'
    function Llamar($metodo, $ruta, $cuerpo, $token) {
      $cab = @{}
      if ($token) { $cab['Authorization'] = "Bearer $token" }
      try {
        $p = @{ Method = $metodo; Uri = "$API$ruta"; Headers = $cab }
        if ($cuerpo) {
          $p.ContentType = 'application/json; charset=utf-8'
          $p.Body = [System.Text.Encoding]::UTF8.GetBytes(($cuerpo | ConvertTo-Json -Depth 5))
        }
        Invoke-RestMethod @p
      } catch {
        Write-Host "HTTP" ([int]$_.Exception.Response.StatusCode) -ForegroundColor Yellow
        $_.ErrorDetails.Message
      }
    }

    # Ingreso de la secretaria (cambia correo y clave)
    $A = (Llamar 'POST' '/auth/ingreso' @{ correo='TU_CORREO_ADMIN'; contrasena='TU_CLAVE' }).token
    # Una fecha 3 dias adelante
    $DIA = (Get-Date).AddDays(3).ToString('yyyy-MM-dd')


PASO 4 - Pruebas (lo esperado va en cada linea)
-----------------------------------------------
1) Registrar especialista en Odontologia general (id 1) y Ortodoncia (id 3):
    $L = Llamar 'POST' '/admin/especialistas' @{ nombre='Dra. Laura Gomez'; especialidadIds=@(1,3) } $null $A
    $L          # 201, con 2 especialidades

2) Publicar 3 horas ese dia:
    Llamar 'POST' "/admin/especialistas/$($L.id)/franjas" @{ fechas=@($DIA); horas=@('08:00','08:30','09:00') } $null $A
    # total 3

3) Lo que ve el paciente:
    Llamar 'GET' '/especialidades'                                       # lista
    Llamar 'GET' '/especialidades/1/especialistas'                       # aparece Laura
    Llamar 'GET' "/especialistas/$($L.id)/calendario?mes=$($DIA.Substring(0,7))"   # el dia con 3 horas
    $H = Llamar 'GET' "/especialistas/$($L.id)/horas?fecha=$DIA"
    $H          # 08:00, 08:30, 09:00

4) Agendar SIN cuenta (usa tu celular para ver el mensaje en la consola):
    $C = Llamar 'POST' '/citas' @{ especialidadId=1; franjaId=$H[0].franjaId; nombreCompleto='Ana Perez'; documento='1075123456'; telefono='318 715 3718'; autorizacionDatos=$true; sitioWeb='' }
    $C.cita; $C.enlaceGestion
    # 201. En la terminal del backend aparece "[WhatsApp -> +573187153718]" con el texto.

5) Lo que debe fallar:
    Llamar 'POST' '/citas' @{ especialidadId=1; franjaId=$H[1].franjaId; nombreCompleto='Ana Perez'; documento='1075123456'; telefono='3187153718'; autorizacionDatos=$true }
    # 409: ya tiene una cita (limite de 1 sin usuario)
    Llamar 'POST' '/citas' @{ especialidadId=1; franjaId=$H[0].franjaId; nombreCompleto='Otra Persona'; documento='22222222'; telefono='3000000000'; autorizacionDatos=$true }
    # 409: esa hora ya no esta disponible
    Llamar 'POST' '/citas' @{ especialidadId=1; franjaId=$H[1].franjaId; nombreCompleto='Otra Persona'; documento='22222222'; telefono='3000000000'; autorizacionDatos=$false }
    # 400: campos.autorizacionDatos

6) Gestionar la cita con el codigo del enlace:
    $COD = ([uri]$C.enlaceGestion).Query.Split('=')[1]
    Llamar 'GET' "/citas/gestion/$COD"                                    # puedeReprogramar y puedeCancelar en True
    Llamar 'POST' "/citas/gestion/$COD/reprogramar" @{ franjaId=$H[2].franjaId }   # 200, ahora 09:00
    Llamar 'POST' "/citas/gestion/$COD/reprogramar" @{ franjaId=$H[1].franjaId }   # 409: ya reprogramo una vez
    Llamar 'POST' "/citas/gestion/$COD/cancelar"                          # 200
    Llamar 'GET' "/especialistas/$($L.id)/horas?fecha=$DIA"               # vuelven las 3 horas

7) Panel de la secretaria:
    Llamar 'GET' "/admin/citas?fecha=$DIA" $null $A                       # la cita, estado cancelada
    Llamar 'GET' '/admin/notificaciones?estado=enviada' $null $A          # confirmacion, reprogramacion, cancelacion
    Llamar 'GET' "/admin/especialistas/$($L.id)/franjas" $null $A         # horas y quien las ocupa

8) Modo manual (opcional): cambia WHATSAPP_MODO=manual en .env, reinicia, agenda otra
   cita y mira  Llamar 'GET' '/admin/notificaciones' $null $A
   Copia el enlaceWhatsApp en el navegador: abre WhatsApp con el mensaje listo.

9) En MySQL: SELECT id, estado, telefono_paciente, LEFT(codigo_gestion_hash,10) FROM citas;
   El telefono debe verse 573187153718 y el codigo solo como hash (64 caracteres).

- 429: demasiados intentos desde tu IP; espera 15 minutos o sube
  LIMITE_ESCRITURAS_POR_IP en el .env mientras pruebas.
